# Chatfuel

> Chatfuel is a no-code AI chatbot and business-automation platform for conversational commerce on Meta-owned messaging channels — WhatsApp, Instagram, Facebook Messenger, TikTok — plus an embeddable website chat widget. It is an official Meta Business Partner. Its public developer surface is small: one documented HTTP endpoint for importing WhatsApp contacts into an automation, plus a live but undocumented GraphQL gateway and a still-responding legacy Broadcasting API whose documentation Chatfuel withdrew in 2026.

> Generated by API Evangelist from the Chatfuel profile at https://github.com/api-evangelist/chatfuel. Chatfuel does not publish an llms.txt of its own: /llms.txt returns 404 on help.chatfuel.com, chatfuel.com, api.chatfuel.com and docs.chatfuel.com. Last verified 2026-08-13.

## APIs

- [Contacts API](https://help.chatfuel.com/create-contacts-in-chatfuel-via-api-23134b06ecf8800683b6efacab24b68d): POST https://panel.chatfuel.com/api/contacts/{automation_id}/whatsapp/ — import up to 1,000 WhatsApp phone numbers into an automation and assign shared contact properties. Authenticated with `Authorization: Bearer {api_token}` from Settings → API. The only documented Chatfuel API operation as of 2026-08-13.
- [Broadcasting API](https://api.chatfuel.com): POST https://api.chatfuel.com/bots/{BOT_ID}/users/{USER_ID}/send with a per-bot `chatfuel_token`. Route still responds but its documentation has been withdrawn; historic limit was 25 requests per second per bot.
- [Dashboard API](https://dashboard.chatfuel.com/api): bot and page management with a bearer Dashboard API token. Documentation withdrawn; no public reference remains.
- GraphQL gateway: https://panel.chatfuel.com/graphql — live behind a WunderGraph Cosmo Router. Introspection is disabled and no SDL is published, so the schema is not publicly readable.

## Specs

- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection is published. https://api.chatfuel.com/swagger.json exists but redirects to a Google SSO login via auth.chatfuel.com.
